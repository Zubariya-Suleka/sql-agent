# sql-agent

**Proves:** "agent development" · "connecting LLMs to … internal databases"

A tool-calling agent that answers questions about the Olist Brazilian e-commerce dataset by writing and running SQL. It runs safely as a read-only database role and calls every model through [llm-gateway](https://github.com/Zubariya-Suleka/llm-gateway).
